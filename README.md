# Retail Sales Analysis using PostgreSQL

## 📌 Project Overview
This project analyzes retail sales data using PostgreSQL to uncover business insights related to sales performance, customer behavior, and product categories.

## 🎯 Objectives
- Analyze retail sales trends.
- Identify top-performing product categories.
- Find high-value customers.
- Study customer demographics.
- Generate business insights using SQL.

## 🛠️ Technologies Used
- PostgreSQL
- SQL
- pgAdmin 4

## 📂 Dataset
- Retail Sales Dataset
- 1000 retail transactions

## 📊 SQL Concepts Used
- SELECT
- WHERE
- ORDER BY
- GROUP BY
- HAVING
- Aggregate Functions
- CASE
- Window Functions (RANK, Running Total)
- Date Functions

## 📈 Business Questions Solved
1. Total Sales
2. Total Orders
3. Average Customer Age
4. Sales by Category
5. Gender-wise Sales
6. Top Customers
7. Monthly Sales
8. Highest Revenue Category
9. Age Group Analysis
10. Running Total of Sales
11. Sales Ranking

## 💡 Key Insights
- Identified the highest revenue-generating product category.
- Ranked customers based on total spending.
- Compared purchasing behavior across genders.
- Analyzed monthly sales trends.
- Grouped customers by age to understand buying patterns.

## 📁 Project Structure

## 🚀 How to Run
1. Create a PostgreSQL database.
2. Create the `retail_sales` table.
3. Import `retail_sales_dataset.csv`.
4. Run the SQL queries from `Retail_Sales_SQL_Project.sql`.
